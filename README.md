# Fuhnetiks
_Fuhnetiks_ is a pronunciation dictionary created with AI tools. It can support all languages (and even conlang!) with your lexical sets (just like the ones by J C Wells), and your morphemes with their shortcuts.

Recently, I've been exploring the phonetic realities (over older RP / GenAm models) of modern British English (SSBE) and General American English. US English set is underway.
